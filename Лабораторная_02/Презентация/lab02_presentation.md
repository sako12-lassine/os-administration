# Настройка sudo

Проверена конфигурация sudo с помощью:

```text

```

# Создание пользователя alice

```text
sudo useradd -G wheel alice
sudo passwd alice
id alice
```

Пользователь `alice` добавлен в группу `wheel`.

![Пользователь alice](../Скриншоты/04_user_alice.png)

# Срок действия пароля

```text
sudo passwd -n 30 -w 3 -x 90 carol
```

- минимальный срок — 30 дней;
- предупреждение — за 3 дня;
- максимальный срок — 90 дней.
