# Цель работы

Получение навыков настройки базовых и специальных прав доступа для групп пользователей в Linux.

# Задание

- Изучить команды `chgrp`, `chmod`, `getfacl`, `setfacl`.
- Настроить базовые разрешения.
- Настроить специальные разрешения.
- Настроить расширенные разрешения с использованием ACL.

# Базовые права доступа

Созданы каталоги:

```text
/data/main
/data/third
Для каталогов назначены группы:

/data/main → main
/data/third → third

Установлены права:

chmod 770 /data/main
chmod 770 /data/third
Проверка доступа

Проверен доступ пользователя bob к каталогам /data/main и /data/third.

Права доступа определяют возможность пользователя переходить в каталог и создавать файлы.

Специальные разрешения

Для общего каталога /data/main установлены:

SGID
Sticky Bit

Команда:

chmod g+s,o+t /data/main
SGID

SGID позволяет новым файлам в каталоге наследовать группу-владельца каталога.

Для /data/main новые файлы получают группу:

main
Sticky Bit

Sticky Bit защищает файлы общего каталога от удаления другими пользователями.

Пользователь может удалять собственные файлы, но не файлы другого пользователя.

ACL

Настроены расширенные разрешения ACL.

Для /data/main предоставлен доступ группе third.

Для /data/third предоставлен доступ группе main.

Использованы команды:

setfacl
getfacl
Default ACL

Настроены ACL по умолчанию для новых файлов.

Это позволяет автоматически наследовать необходимые разрешения при создании новых объектов.

Проверка пользователя carol

Проверена работа ACL от имени пользователя carol.
